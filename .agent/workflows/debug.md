# /debug — Structured Debugging

1. REPRODUCE: confirm the issue is consistently reproducible
2. ISOLATE: narrow down to the smallest failing case
3. HYPOTHESIZE: propose 2–3 likely root causes
4. FIX: implement the most likely fix
5. VERIFY: confirm issue is resolved, no regressions
6. DOCUMENT: add finding to AGENTS.md Section 8 as anti-pattern if relevant
