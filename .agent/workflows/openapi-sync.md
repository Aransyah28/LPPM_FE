# OpenAPI Sync Workflow

This workflow automates the process of extracting the merged OpenAPI specification generated by the backend and updating the frontend's API client bindings. This is useful whenever changes are made to the backend schema or endpoints and you need the frontend code to reflect these updates.

// turbo-all

1. Generate the latest OpenAPI specification at the Backend:

```bash
cd ../be-sdnjoglo05pagi && bun run openapi:generate
```

2. Copy the generated `openapi-merged.json` into the Frontend workspace:

```bash
cp ../be-sdnjoglo05pagi/openapi-merged.json ./openapi-merged.json
```

3. Regenerate the API bindings within the Frontend:

```bash
bun run api:generate
```
